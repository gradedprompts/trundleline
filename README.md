# Trundleline

A toy-train arcade game in one HTML file, built by a single prompt in Cursor (Grok 4.7, medium effort).

Play it: https://gradedprompts.github.io/trundleline/

`index.html` is the unedited output of one run of the prompt. Nothing was changed by hand after the run.
SHA-256: `7b0e1930fdf6de2f21cec7ca6f0b52ca0df333efd5dce2616a14a1d3797add54`

How it plays: a red engine runs over a rug in a blue toy tray and never stops. Each passenger it picks up adds a wagon; driving onto the station delivers every wagon at once, and the more passengers arrive together, the more each one pays. The train speeds up as it grows, and hitting the edge, a block or its own wagons ends the run. Eight maps, three stars to earn on each; your best scores and stars are saved in your browser.

Steer with the arrow keys or W A S D, or swipe on a phone. Space starts the next map, P or Esc pauses, M toggles sound, and the keys 1 to 8 pick an open map. It needs no network at all. Add `?map=3` to the address to start a map straight away.

The prompt that built it is being prepared for Graded Prompts: https://www.gradedprompts.com/prompts/apps
